## Getting Started

### Local Setup
1. Clone the repo.
2. Make sure you have python installed.
3. Run `python Human_AI_Teaming_Starter_Pack/Python_App/main_app.py`

### Run via Docker (Cloud-Native) 🐳
Since this is a GUI application (Tkinter), you can run it via Docker Compose using X11 forwarding:
```bash
# Ensure your X server allows connections (e.g. xhost +local:docker)
docker-compose up --build
```

## Description
Contains resources, a Python application, presentations, and report templates for studying and implementing Human-AI teaming dynamics.
